This project is a **responsive News Web Application** that dynamically fetches and displays real-time news data from a public API. It is built using **HTML, CSS, and JavaScript**, focusing on modern UI design and efficient API integration.

The application allows users to search for news articles using a real-time **debounced search feature**, which minimizes unnecessary API calls and improves performance. It also includes **category filters** such as General, Technology, Sports, and Business, enabling users to quickly access relevant content. News articles are displayed as visually appealing cards with images, titles, short descriptions, and links to full articles.

The interface features a **premium UI design** with glassmorphism effects, gradient themes, smooth animations, and responsive layouts that adapt seamlessly across devices. A **dark/light mode toggle** enhances user experience by allowing theme customization. Additionally, the app highlights searched keywords within results for better readability.

To improve usability, the application stores **recent search history** using local storage, allowing users to revisit previous queries easily. It also supports **pagination (Load More)** to efficiently handle large datasets without overwhelming the interface.

Overall, this project demonstrates practical implementation of **API integration, dynamic DOM manipulation, responsive design, and modern UI/UX principles**, making it suitable for both learning and portfolio purposes.
